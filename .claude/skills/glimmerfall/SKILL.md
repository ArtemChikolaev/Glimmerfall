# Работа в Glimmerfall

1. Прочитай [CLAUDE.md](../../../CLAUDE.md) (он же AGENTS.md) и [маршрутизацию](../../../docs/ai/INDEX.md). Указания пользователя имеют приоритет над процедурами скиллов в рамках правил среды.
2. По задаче открой только нужные профильные SKILL.md; references загружай по необходимости. Не читай весь каталог заранее.
3. Перед новым кодом найди точки расширения ([discovery-before-code](../discovery-before-code/SKILL.md)). Для сложной работы кратко сообщи план ([plan-first-communication](../plan-first-communication/SKILL.md)) и продолжай в порученных границах.
4. Сверяй решения с [PRD](../../../docs/PRD.md) и ADR в `docs/adr/`. Расхождение объясни; новое продуктовое решение владельца записывай в PRD или ADR.
5. Правь канонические файлы, сохраняй чужие изменения. До завершения — [self-review-checklist](../self-review-checklist/SKILL.md).
6. При запросе анализа отделяй факты, ограничения проверки и предложения. Не реализуй дизайн-предложения без поручения на реализацию.

Router общий для Claude Code и Codex. Доступные инструменты определяет текущая среда. Пути команд считаются от корня репозитория, если не указано иначе.
