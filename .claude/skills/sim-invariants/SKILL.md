# Инварианты сима

Каждый пункт — шишка Аркады aegis-draft, стоившая часов.

1. **Модалки не блокируют тик.** Выбор благословения, магазин, драфт и лут — состояния сима, которые разрешаются вводом; один источник истины `activeModal`. Бот разрешает модалку раньше мировых действий; каждый цикл шагов — с лимитом итераций и сторожем «тик не двигается». Иначе прогон висит вечно и выглядит как «медленный забег» — однажды CI висел шесть часов.
2. **Пулы безопасны.** Ссылки на сущность чистятся при смерти; спавн откладывается в конец тика — иначе пул отдаст объект умирающего, и остаток функции прочитает новичка (так босс однажды «ожил» в рядовом враге и испортил замеры нескольких версий). Эффекты смерти по соседям — через очередь, а не рекурсией.
3. **Способность ищется по виду, не по слоту.** У каждого числового поля явные единицы (тики или секунды, пиксели или тайлы, формат фиксированной точки); тест «каждый вид читает своё значение».
4. **Данные героя в забеге — копия.** Таланты и благословения правят копию, а не общий контент, иначе правка протечёт в следующий забег.
5. **Числа в UI — из тех же функций, что и в симе.** Подсказка с цифрами считает их общей функцией; тест ловит расхождение.
6. **Один конвейер предложений.** Все источники благословений идут через него — там слоты типов и лимиты. Новое поле врага получает значение по умолчанию в одном месте, иначе оно молча пустое у всех видов.
7. **Отряд — часть сима.** Свап, ассист и связка — это ввод; состояние резерва (здоровье, кулдауны, заряд) обновляется детерминированно; смерть активного героя — вынужденный свап. Ко-оп — тот же сим с вводом по игроку на тик, без особых веток для соло.

Проверь воспроизводимый сид, граничный случай изменённой механики и законченный цикл (акт с боссом). Новую механику игрока бот должен уметь применять ([balance-harness](../balance-harness/SKILL.md)), иначе её карты для него — мёртвые выборы. Детерминизм — [sim-determinism](../sim-determinism/SKILL.md).
