# Glimmerfall

Изометрический пиксельный экшн-рогалик: отряд из трёх фонарщиков несёт свет через мир, который поглощает Тьма. Драфт героев с «сыгранностью», переключение посреди орды, огонь и молнии покровителей, дейлики с призраками друзей.

> Рабочее название. Статус — **препродакшн**: кода игры ещё нет, идут решения этапа 0 и подготовка технических спайков (см. [BACKLOG](docs/BACKLOG.md)).

## Стек (план, ADR 0002)
| Слой | Технология | Роль |
|---|---|---|
| `sim/` | чистый C# (.NET), фиксированная точка | вся игровая логика: детерминированно, headless, без движка |
| `game/` | Godot 4.7 (.NET) | презентация: рендер, VFX, звук, UI, ввод, платформы |
| `content/` | JSON + JSON Schema | герои, покровители, благословения, враги, акты |
| `tools/` | Python + Blender | 3D → пиксельные спрайт-листы, QA спрайтов, утилиты |
| `server/` | Go | дейлики, приём и ре-симуляция реплеев, лидерборды |
