# Сценарии выбора скиллов

Ручной набор ожиданий (2026-10-26), а не результат автоматического вызова Claude или Codex. Положительные случаи: прямой, перефразированный, проектный, бытовой. Отрицательные: соседняя область, посторонний запрос, неоднозначный запрос без достаточного основания. Отрицание касается конкретного скилла — другие скиллы при этом могут быть уместны.
