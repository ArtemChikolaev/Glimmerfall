## Пины в репозитории
- `global.json` — SDK `10.0.400` с `rollForward: latestPatch` (любой патч 10.0.4xx) и `dotnet test` на Microsoft Testing Platform.
- `.godot-version` — `4.7.2-stable`; `game/Glimmerfall.csproj` — `Godot.NET.Sdk/4.7.2` (CI сверяет, что они совпадают); `tools/ci/install-godot.sh` — закреплённый SHA-512 Linux-сборки для CI.
- Пакеты NuGet — точные версии в csproj (`xunit.v3` 4.0.2).
- Обновление любого пина — только за зелёным CI (ADR 0002).

## Изменения вне репозитория
