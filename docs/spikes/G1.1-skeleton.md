## Структура
| Проект | Что | Цель |
|---|---|---|
| `sim/Glimmerfall.Sim.csproj` | чистый C#: правила, сущности, фиксированная точка, PRNG, хеш, реплей, боты | `netstandard2.1` |
| `sim.tests/Glimmerfall.Sim.Tests.csproj` | xUnit v3 на Microsoft Testing Platform, golden-реплеи | `net10.0` |
| `sim.cli/Glimmerfall.Sim.Cli.csproj` | `glimmerfall-sim`: bench, bot, career, record, verify, digest | `net10.0` |
| `game/Glimmerfall.csproj` | Godot 4.7.2 .NET: только презентация | `net10.0` (Android — `net9.0`) |
| `server/` | Go-каркас сервера ([G1.7](G1.7-server.md)) | Go 1.26 |
| `validator/Dockerfile` | тот же Sim.dll в контейнере | .NET 10 |

`Glimmerfall.slnx` — все C#-проекты; `game/Glimmerfall.sln` — для редактора и экспорта Godot (ему нужен классический `.sln` рядом с проектом).

## Команды (из корня)
```bash
dotnet build Glimmerfall.slnx
dotnet test --project sim.tests/Glimmerfall.Sim.Tests.csproj
tools/godot.sh --headless --path game --import
tools/godot.sh --headless --path game --fixed-fps 60 -- --smoke-frames 240
```

## CI (`.github/workflows/ci.yml`)
- `skills` — валидатор скиллов (был).
- `sim` — матрица Linux x64 / Windows x64 / macOS arm64: сборка, тесты (с golden-реплеями), набор дайджестов.
- `determinism` — побайтовая сверка дайджестов трёх ОС.
- `godot` — сверка пинов, Godot 4.7.2 из кэша со сверкой SHA-512, сборка C#, headless-импорт, смоук сцены орды (240 кадров, код выхода).
- `server` — gofmt, vet, тесты Go с настоящим .NET-валидатором.
- `validator` — сборка Docker-образа и проверка golden-реплея внутри него.

Действия обновлены до текущих мажорных версий (checkout v7, setup-python v7, setup-dotnet v6, setup-go v7, cache v6, upload-artifact v7, download-artifact v8).
