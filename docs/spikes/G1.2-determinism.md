# G1.2 — Детерминизм сима (2026-10-26)

**Итог:** формат и механизмы выбраны и закреплены тестами; бит-в-бит на одной машине, между Debug/Release и между хостами (CLI и Godot) подтверждено. Матрица Windows x64 / Linux x64 / macOS arm64 собрана в CI, но **на GitHub ещё не запускалась**: push — по поручению владельца.

## Решения
| Что | Решение | Почему |
|---|---|---|
| Фиксированная точка | `Fix` — Q48.16 в `long` (`sim/Numerics/Fix.cs`) | Q16.16 в `int` переполняется уже на 200 × 200; в 64 битах произведение безопасно до \|a·b\| < 2³¹ в реальных единицах. Тот же формат у Photon Quantum |
| Тригонометрия | таблицы четверти синуса и октанта арктангенса по 1025 точек с линейной интерполяцией (`TrigTables.g.cs` из `tools/gen_trig_tables.py`) | ни одного вызова libm; ошибка sin/cos ≤ 2/65536, atan2 ≤ 3 единицы угла из 65536 — проверено на всех углах |
| Корень | целочисленный Ньютон сверху (`FixMath.ISqrt`), точный floor | проверен против BigInteger на всём диапазоне `ulong` |
| PRNG | PCG32 XSH-RR, поток на подсистему (`RngStream`: Spawn, Combat, Offers, Ai, Loot, Places, Draft) | эталон pcg32-demo совпал; сид потока зависит только от сида забега и номера — новый поток не сдвигает старые (закреплено тестом) |
| Сид из строки | FNV-1a 64 по UTF-16 (`SeedHash.FromString`) | `string.GetHashCode` рандомизирован на процесс; та же функция в Go-сервере дала тот же вектор |
| Хеш состояния | раунд и лавина xxHash64 по 64-битным словам (`StateHasher`), версия раскладки `World.DigestLayoutVersion` | 5 тыс. врагов хешируются за доли миллисекунды |
| Реплей | текст: версия баланса, сид, заголовок конфига, оверрайды, **отпечаток данных**, лог ввода по шагам (base64url, дельта шага varint + 4 байта), дайджест каждые N шагов | дифф golden показывает, с какой контрольной точки разошлось; изменённые данные без бампа версии отказываются явно |
| Целевой фреймворк сима | `netstandard2.1` | тот же Sim.dll грузят Godot (.NET 10), CLI, сервер-валидатор и запасной путь Unity (Mono) |

## Проверки (все зелёные локально)
- `sim.tests` (около 7 с): эталоны PCG32 и SplitMix64, точность Fix и тригонометрии, закреплённые сиды потоков и хеш, раундтрип реплея через текст, подмена ввода ловится на контрольной точке, отказ по версии баланса и по отпечатку данных, инварианты, 4 golden-реплея (`sim.tests/golden`, перезапись — `sim.tests/golden/regenerate.sh`).
- **Тест-запрет по IL** (`SimPurityTests`): ссылки на сборки (только `netstandard`), типы (`Math`, `MathF`, `Random`, `DateTime`, `Stopwatch`, `Environment`, потоки, `Task`, перечислители `Dictionary`/`HashSet`, `Godot.*`, `UnityEngine.*`, `System.Numerics`, интринсики) и float/double в сигнатурах полей, методов, локальных переменных, generic-инстанциациях и опкодах. Сторож: на сборке тестов сканер обязан найти нарушения. Первая же находка — `yield return` в сим-коде тянет `Environment.CurrentManagedThreadId` (заменён массивом).
- Кросс-хост: 240 тиков спайка орды в Godot 4.7.2 (Debug-сборка сима) и в CLI (Release) — один дайджест `93dc505a94c2fa76`.
- `glimmerfall-sim digest` — набор из 7 прогонов (кайтер, AFK, орда); CI печатает его на трёх ОС и сравнивает файлы побайтно (джоб `determinism`).
