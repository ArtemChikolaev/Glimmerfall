# G1.5 — Бот-харнесс (2026-10-26)

**Итог:** харнесс работает headless на том же Sim.dll; бот проходит акт; гейт «AFK умирает» измерим с первого дня. Числа ниже — замеры **заглушечного баланса спайка** (данные `sim/Content/SpikeContent.cs`), а не цели; калибровка — G3.4.

## Что перенесено из `sim_arcade` aegis-draft (идеи, не код)
- **Кайтер:** уходит от взвешенного центра масс врагов в радиусе 200 px с поворотом «по кругу», уклоняется от телеграфов (круг удара босса, линия тарана, снаряды стрелков), рывком выходит из окружения, держится от стен, собирает опыт, свапает героя на низком здоровье, у босса держит дистанцию атаки. Курс квантован до 64 направлений — реплей короче в 5 раз.
- **AFK** и **AFK со N-й секунды** (`afk-after:120` — играет кайтером, потом стоит: ориентир PRD «≤ 20 с ко 2-й минуте»).
- **Модалки первыми:** бот разрешает выбор благословения и чекпоинт раньше мировых действий; `RunDriver` держит потолок тиков, потолок шагов и сторож «тик стоит 600 шагов» (тест ловит политику, игнорирующую модалку).
- **Карьера:** забеги подряд; угли за забег тратятся на мету (урон, здоровье, скорость, радиус подбора), тир растёт после победы.
- **Статистика по актам:** дошли, закрыли, перцентили времени гибели в акте, медианы убийств, элит, уровня, урона, смертей героев, свапов, рывков, пика врагов; гибели по минутам и по убийце; `--dump FILE` — JSON для офлайн-свипа; `--set` для A/B с громкой ошибкой на неизвестный ключ; лишний аргумент или ключ — тоже ошибка (так нашёлся молча терявшийся путь дампа).

## Замеры (тир 0, акты по 8 мин, n = 36, ±1 стандартная ошибка)
| Политика | Результат |
|---|---|
| AFK | гибнет в 36 из 36, время p25/p50/p75 — 1:36 / 1:38 / 1:41; добивают стрелки (36/36) |
| AFK со 2-й минуты | гибнет через 11–17 с после остановки (2:11 / 2:13 / 2:17) — укладывается в ориентир PRD |
| Кайтер, 1 акт | акт закрыт в 36 из 36; урон за акт p50 290, герои не падали, 48 рывков |
| Кайтер, 3 акта, тир 0 | победа 2,8% ±2,7; акт 1 — 94%, акт 2 — 53%, акт 3 — 3% |
| Кайтер, 3 акта, тир 1 / 2 / 4 | акт 1 закрыт в 78% / 39% / 3% |

Гибели кайтера кучкуются на 7:12–9:56 времени акта — на боссе (он выходит на 7:00).

Карьера, 30 забегов по 3 акта: тир 0 всю серию, одна победа (3,3% ±3,3) — на последнем забеге. Мета дошла до потолка 5/5/5/5: вся она стоит 1200 углей, а за серию заработано 6613 (5413 осталось), то есть экономика меты слишком щедрая — и при этом полная мета стену босса не снимает.

## Что это говорит дизайну (для G3.4, не решения)
- Гейт угрозы для AFK уже соблюдается; основная угроза AFK — стрелки.
- Полный забег на базовом тире слишком труден (2,8% при ориентире PRD 30–50%), а стена — босс каждого акта при росте здоровья врагов +70% за акт. Рычаги для замера: здоровье босса, рост за акт, темп спавна во время босса.
- Мета насыщается быстро и почти не влияет на исход — её силу и цену калибровать вместе с лестницей, карьерой (скилл `balance-harness`).
- Слепые зоны бота: не выбирает героя при свапе (берёт следующего живого), не ходит к «местам» карты (их ещё нет), выбор благословений — фиксированный приоритет. Замеры с этими ограничениями — артефакты бота, а не свойства игры.
