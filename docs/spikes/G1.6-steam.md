# G1.6 — Steam: план (2026-10-26)

**Итог:** спланировано, не начато. Блокер — аккаунт Steamworks: он требует юрлица и маршрута выплат ([G0.6](../BACKLOG.md)), а SDK Steamworks распространяется только по соглашению партнёра. Поэтому в репозиторий пока не попадают ни SDK, ни его бинарники.

## Что уже готово со стороны игры
- Реплей — компактный текст с отпечатком данных и дайджестами ([G1.2](G1.2-determinism.md)); сервер его ре-симулирует и считает очки сам ([G1.7](G1.7-server.md)). Это основа trusted-лидербордов.
- Весь ввод — `InputFrame`: слой Steam Input сводится к ещё одному источнику кадра ввода рядом с клавиатурой, геймпадом и тачем.
- Linux-сборка для Steam Deck экспортируется ([G1.3](G1.3-horde.md)).

## План
1. **Библиотека.** Для C#-проекта — Steamworks.NET (MIT, прямой C#-API steam_api) за интерфейсом платформы в `game/` (достижения, облако, лидерборды, глифы ввода) с пустой реализацией для сборок без Steam (телефоны, DRM-free). GodotSteam 4.22 (GDExtension под Godot 4.7.2) — запасной вариант: из C# он доступен только через динамические вызовы.
2. **Проверка на Spacewar (AppID 480)** до своего AppID: инициализация, оверлей на Deck и Windows, тестовое достижение.
3. **Steam Input:** манифест действий (движение, рывок, свап, ассист, выбор), глифы из `ISteamInput` в подсказках UI, проверка на Deck.
4. **Steam Cloud:** Auto-Cloud для профиля и сейва забега (сохранение в любой момент — G3.6).
5. **Trusted-лидерборды:** запись очков только сервером через Web API (`ISteamLeaderboards/SetLeaderboardScore`, ключ издателя — только в env сервера); клиент шлёт реплей на наш сервер. Реплей как UGC: проверить, можно ли прикреплять UGC клиентом к trusted-доске; иначе — хранить реплеи у себя и класть их id в детали записи.
6. **Steam Deck Verified:** 1280×800, глифы Deck, текст ≥ 9 px, без лаунчера, оффлайн-режим.

## Нужно от владельца
- Решение G0.6 (юрлицо и выплаты) → аккаунт Steamworks, AppID ($100), ключ Web API издателя.
- Подпись macOS-сборок (Developer ID) и нотаризация: встроенная ad-hoc-подпись Godot на macOS 26.5 даёт SIGKILL при запуске ([G1.3](G1.3-horde.md)).
